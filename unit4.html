It의 여러 가지 쓰임

가주어·강조·가목적어·비인칭
이름:

개념 쏙쏙!

작은 단어 It은 변신을 잘해요! 4가지 변신을 알아봐요. 🪄

① 가주어 It — 진짜 주어(to부정사·동명사·that절)가 길어서 뒤로 보내고 앞에 쓰는 It (뜻 없음)
It is important to exercise. (운동하는 것은 중요하다)
② 강조구문 It is ~ that … — 강조하고 싶은 말을 It is 와 that 사이에 쏙!
It was her that I met. (내가 만난 건 바로 그녀였다)
③ 가목적어 It — think/find/make 뒤에서 목적어가 길 때 쓰는 It (뜻 없음)
I think it bad to eat much at night.
④ 비인칭 주어 It — 시간·날짜·요일·날씨·거리 (뜻 없음) / 대명사 It — '그것'
It is seven o'clock. (시간) / It is on my desk. (그것=대명사)
💡 가주어 vs 강조 구분법
be동사와 that 사이에 형용사 → 무조건 가주어!
부사(구) → 무조건 강조구문!
(대)명사 → that 빼고 나머지가 완전한 문장이면 가주어, 빠진 게 있으면 강조!

연습문제

먼저 가주어 It 문장을 단어를 배열해서 만들어 보아요! 🧱

🧱 가주어 It — 문장 만들기
괄호 속 단어를 모두 배열해 문장을 완성해요.
01. Tom이 Amy와 사랑에 빠진 것은 사실이다.
📦 it / Amy / Tom / in / true / is / love / fell / with / that
⭕ 정답이에요! 잘했어요!
정답: It is true that Tom fell in love with Amy.
02. 밤에 혼자 외출하는 것은 위험하다.
📦 it / dangerous / is / out / at / go / alone / night / to
⭕ 정답이에요! 잘했어요!
정답: It is dangerous to go out alone at night.
03. 외국어를 배우는 것은 흥미롭다.
📦 it / learning / interesting / language / is / foreign / a
⭕ 정답이에요! 잘했어요!
정답: It is interesting learning a foreign language.
04. 공공장소에서 흡연하는 것은 무례하다.
📦 it / to / public / smoke / impolite / is / places / in
⭕ 정답이에요! 잘했어요!
정답: It is impolite to smoke in public places.
05. 네가 약속을 지키는 것은 중요하다.
📦 it / you / your / important / word / that / keep / is
⭕ 정답이에요! 잘했어요!
정답: It is important that you keep your word.

🧱 가목적어 It — 문장 만들기
괄호 속 단어를 모두 배열해 문장을 완성해요.
01. 나는 가난한 사람들을 돕는 것이 의무라고 생각한다.
📦 it / I / helping / obligation / the poor / think
⭕ 정답이에요! 잘했어요!
정답: I think it obligation helping the poor.
02. 그녀는 아기들을 돌보는 것이 어렵다는 것을 알았다.
📦 it / she / look after / to / difficult / babies / found
⭕ 정답이에요! 잘했어요!
정답: She found it difficult to look after babies.
03. 우리는 그가 헌혈한 것이 좋다고 생각했다.
📦 it / we / donated / nice / blood / that / he / thought
⭕ 정답이에요! 잘했어요!
정답: We thought it nice that he donated blood.
04. Ben은 물을 아끼는 것이 중요하다는 것을 알았다.
📦 it / Ben / found / water / important / saving
⭕ 정답이에요! 잘했어요!
정답: Ben found it important saving water.
05. Tim은 7시에 일어나는 것을 규칙으로 만들었다.
📦 it / Tim / a rule / to / made / get up / at / seven
⭕ 정답이에요! 잘했어요!
정답: Tim made it a rule to get up at seven.
